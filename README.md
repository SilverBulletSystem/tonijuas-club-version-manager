# Tonijuas Club · documentos legales

Sitio estático para GitHub Pages con los documentos legales de Tonijuas Club.

- `terminos/` — versión vigente de los Términos y Condiciones.
- `terminos/<versión>/` — copia congelada de cada versión publicada (hoy: `1.0.0`).

Para publicar una versión nueva: copia la vigente a `terminos/<nueva-versión>/`, actualiza `terminos/index.html` y agrega una fila al historial de versiones. Marca el commit con el tag `terminos-v<versión>`.
